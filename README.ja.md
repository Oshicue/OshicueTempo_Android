# Oshicue Tempo (Android)

[简体中文](README.md) · [繁體中文](README.zh-Hant.md) · **日本語** · [English](README.en.md)

ファン特典会の現場で使う、ネイティブ Android のマルチメンバータイマー。**Tempo** は「リズム」の意味。

これは `OshicueTempo_iOS`（SwiftUI のネイティブ iOS App）の完全な Android 移植です：Kotlin + Jetpack Compose、MediaPlayer、AlarmManager、NotificationChannel を使用し、最小 Android 10（API 29）、ネットワークやアカウントへの依存はなく、サードパーティのランタイムライブラリもありません。

## ビルドと実行

Android Studio でこのディレクトリを開くか（またはコマンドラインで）、JDK 17 以上を使用します：

```sh
./gradlew :app:assembleDebug          # デバッグビルド
./gradlew :app:testDebugUnitTest      # コアと永続化のテスト（16 件）
./gradlew :app:assembleRelease        # 署名済みリリース（keystore.properties が必要）
```

リリース署名は iOS プロジェクトのチーム設定と同じ考え方です：リポジトリ内の `oshicue-tempo-release.jks` と `keystore.properties` が自己署名の設定を提供します。`keystore.properties` がない場合は未署名のビルドのみが生成されます。ビルド済みの成果物：

- `OshicueTempo-Android-1.0.0.apk`（R8 収縮済みの署名リリース、約 3.6 MB）
- `OshicueTempo-Android-1.0.0-debug.apk`
- `OshicueTempo-Android-1.0.0-Source.zip`（ソースアーカイブ。署名素材とビルド成果物は含みません）

## 使い方

1. 右上の管理ボタンをタップしてグループを作成し、グループ名と券1枚あたりの秒数（1〜3600 秒）を設定します。
2. メンバーを追加し、名前、担当カラー、それぞれの終了音を設定します。
3. メイン画面で現在のグループを選択します。1 ページに 4 人まで表示され、それ以上は左右にページを切り替えられます。ページドットの両側の矢印でも操作できます。
4. メンバーの時計をタップし、テンキーで今回の券の枚数を入力し、「確認してカウントダウン開始」をタップするとすぐに始まります。**合計時間 = 券1枚あたりの秒数 × 今回の券数**。
5. 各メンバーは個別に一時停止・再開・リセット・次の回の開始ができます。グループを切り替えても、他のメンバーのカウントダウンは止まりません。

編集可能な架空のグループ LUMINA と 4 人のメンバーが同梱されており、初回起動時に試せます。サンプルを削除して実際のグループを追加してください。

1 回の券数は 1〜999 枚、1 回の計測は最大 24 時間です。開始済みの回は開始時の券単価を保持し、グループの時間を編集しても進行中の回は変わりません。メンバーやグループを削除して保存すると、関連するタイマーと通知が取り消されます。リセットには確認が必要です。

## 通知音と録音の読み込み

星光・ハートビート・ベル・レベルアップの 4 種類のオリジナル通知音を内蔵し、「サウンドと通知」で試聴できます。複数のメンバーが同時に終了した場合、フォアグラウンドではそれぞれの通知音が同時にミックス再生され、人数に応じて音量が自動的に均等配分されます。

録音の読み込み：「サウンドと通知」で「ファイルから録音を読み込む」をタップし、システムのファイル選択（SAF）で音声を選びます。M4A、WAV、AIFF、CAF、MP3、AAC に対応し、録音は 30 秒未満かつ 50 MB 以下である必要があります。読み込んだ音声は通知チャンネル用にシステムの通知音ディレクトリ（MediaStore）にもコピーされ、アプリ内の再生にはアプリ専用ディレクトリの元ファイルを使用します。

フォアグラウンドではメディア音量で再生し、他のアプリの音量を自動的に下げるオーディオフォーカスを要求します。計測中は画面が常時点灯します。ロック画面とバックグラウンドの通知は AlarmManager の正確なアラームで発火し、通知音ごとに高重要度の通知チャンネルを 1 つ使います（通知権限が必要）。正確なアラームの権限が取り消された場合は、精度の低い（遅延する可能性のある）通知に切り替わります。現場で使う前に実機で試聴し、通知権限と音量を確認してください。

カウントダウンは絶対的な締め切り時刻で計算されるため、アプリの切り替え・ロック・再起動後も正しい残り時間に復元されます。端末の再起動やアプリの更新後も、進行中の通知は自動的に再スケジュールされます。期限切れの回はフォアグラウンドに戻ったときに「時間です」と表示され、バックグラウンド通知で処理済みの音を重複再生しません。

## 外観

ライトとダークのインターフェースはシステムの外観に自動で従い、アプリ内に切り替えスイッチはありません。ライトは純白の背景とわずかに色づいた白いカード、ダークは Oshicue の黒を保ちます。システムの外観が変わると、タイマーボード、入力シート、テンキー、グループとメンバーの編集、サウンド設定が一緒に更新され、開始済みまたは一時停止中のタイマーはリセットされません。

メンバーの元の担当カラーは常に保持され、カラードットとタイマーリングは両方の外観で同じ担当カラーを使います（iOS と同じコントラスト補正アルゴリズム）。ライトでは読みやすいニュートラルな濃色の文字を使い、カードの色付けと影も控えめです。白い担当カラーの時計には細いニュートラルな縁取りが付きます。ワードマークとカウントダウンの数字は同梱の Unbounded 可変フォントを使い続けます。

## 言語サポート

簡体字中国語、繁体字中国語、日本語、英語をネイティブにサポートし、システム言語に自動で従います。Android 13 以降ではシステム設定の「アプリの言語」で個別に切り替えられます（`localeConfig` で宣言）。インターフェース、アクセシビリティラベル、エラーメッセージ、通知音の名前、ローカル通知はすべて翻訳済みです。ユーザーが入力したグループ名、メンバー名、録音名はそのまま保持されます。

英語のインターフェースのみイベントを **MEET & GREET** と呼び、簡体字中国語と日本語では **特典会**、繁体字中国語では **特典會** を使用します。

## データとブランド

グループ、メンバー、選択中のグループ、各回のタイマーはアプリ専用ディレクトリの `files/OshicueTempo/state.json` に自動保存されます。JSON 構造は iOS 版と完全に同じ（`version: 1`、キーのソート順、`millisecondsSince1970` の日付、null の省略）なので、どちらのプラットフォームで書いたデータも相互に読み込めます。書き込みは一時ファイルによるアトミック置換で行い、読み込みに失敗した場合は元のデータを保持して書き込みを停止します。

Oshicue ブランドカラー（黒 `#0A0A0D`、ウォームホワイト `#F4F3EE`、ピンク `#FF3D6E`）を踏襲しています。ワードマークとタイマーの数字には **Unbounded** 可変フォント（SIL Open Font License、ライセンスは `app/src/main/assets/licenses/` に同梱）を使用します。アイコンとワードマークは iOS プロジェクトのブランド素材（`docs/brand/`）を引き継ぎ、アダプティブランチャーアイコンは `tools/generate_launcher_icons.swift` で生成します。

## プロジェクトと検証

- `app/src/main/kotlin/com/oshicue/tempo/App`：アプリのライフサイクルと画面の連携（`TempoApplication`、`MainActivity`、`TempoRoot`）。
- `app/src/main/kotlin/com/oshicue/tempo/core`：グループ、メンバー、カウントダウンのモデル、入力検証とスナップショット JSON のエンコード・デコード。
- `app/src/main/kotlin/com/oshicue/tempo/data`：`TempoStore` の永続化、`TempoAudio` の再生と読み込み、`TempoNotifications` の通知チャンネルとアラーム、ブロードキャストレシーバー。
- `app/src/main/kotlin/com/oshicue/tempo/ui`：4 人のタイマーボード、券数の入力、グループ編集、サウンド設定。
- `app/src/main/kotlin/com/oshicue/tempo/i18n`：iOS の `Localizable.strings` から生成したキーマップ。
- `app/src/test`：時間の計算、状態の永続化、異常系のテスト（16 件）。
- `tools/convert_localization.py`：iOS のリソースディレクトリから 4 言語の文字列とキーマップを再生成します。
- `../misc/OshicueTempo_iOS/`：ワークスペースでプロジェクトディレクトリと同階層の `misc/` に置いた移植の参照用 iOS ソース（元のアーカイブを含む。ソースアーカイブには含まれません）。

```sh
python3 tools/convert_localization.py ../misc/OshicueTempo_iOS/OshicueTempo/Core/Resources \
  app/src/main/res app/src/main/kotlin/com/oshicue/tempo/i18n
swift tools/generate_launcher_icons.swift ../misc/OshicueTempo_iOS/docs/brand/app-icon.png app/src/main/res
```

現在の検証結果は `docs/VERIFICATION.md` を参照してください。
